- **User artifact:** a meeting whose visible participant statements have deliberately different depth by the selected profile, while retaining independent proposals, grounded critique, source-linked cards, bounded rounds, and readable final output.
- **Baseline:** the UI displays the validated `statement` directly, without a summarization pass. Medium/default prompts are 140/120/80 words; `lite` and `unlimited` have different transport caps but the same speech instruction. Final synthesis already has a separate output-profile path. Existing 4,000-character statement validation and Card/Canonical State limits remain.
- **Smallest hypothesis:** pass the parsed Output Profile into the existing proposal, review, and targeted-debate prompt builders and make their statement guidance profile-specific. Lite should be brief, Medium preserve the current balance, and Uncapped allow a developed but focused contribution. Keep the same Turn Envelope, parser, provider caps, call counts, retry policy and task-specific Review source rules.
- **Expected information gain:** offline mocked provider requests can prove all three profiles deliver distinct speech instructions through both one-shot and resumable phases, without paid calls. This tests instruction routing, not model compliance or quality.
- **Acceptance:** Lite/Medium/Uncapped proposal, cross-review and targeted prompts differ in intended speech depth; Medium keeps the old ceilings; Review still asks for source-bounded Findings; all profiles retain the existing structured contract, language rule, and provider cap. Complete `pnpm.cmd check`; no UI clipping or stored-room schema change.
- **Cost boundary:** zero live provider calls and no extra rounds, retries, dependencies, migrations, or deployment. Uncapped may consume more input/output and reading effort during real use; existing provider and room budgets remain authoritative. Test only offline fixtures.
- **Stop:** if a profile cannot fit the current validated statement/Card contract, do not loosen the parser or add a repair call in this slice; report the mismatch and keep the bounded behavior. Actual speech length and value require later authorized live evidence.

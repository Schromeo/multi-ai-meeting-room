## Failure 1 - Verifier Contract

The Editor completed and its output passed the strict Change Set parser. The Anthropic Verifier then returned structured output that failed the top-level changed-material contract. The original parser reported only a generic mismatch, so the exact invalid field was not observable.

The implementation was corrected without another provider call:

- the prompt now emits a concrete response skeleton containing every real Change ID;
- it explicitly permits only `summary`, `checks`, and `unresolved` at the top level;
- it explicitly forbids model-authored `verdict`, `confidence`, and `evidence` fields;
- each status must be one literal value rather than the pipe-separated option list;
- parser failures now identify invalid JSON, missing or unexpected keys, invalid arrays, unknown Change IDs, invalid statuses, and bounded-note failures separately.

## Failure 2 - False Recovery Boundary

The old v0.11c implementation grouped Editor and Verifier into one synthesis transition. Although the UI offered an explicit Resume action, the failed transition had already consumed both reserved agent turns. Resume therefore stopped before any provider call with `Budget exhausted`.

This contradicted the product's recovery promise and would also have repeated the successful Editor call if additional budget had been available.

The implementation was corrected without another provider call:

- a validated Editor result now emits and persists a `ReviewEditCheckpoint` containing Change Set, deterministic Artifact v2, Editor snapshot, source State version, and creation time;
- a resumed synthesis request must match the same State version, accepted Findings, Artifact v1, and deterministic Editor;
- resume routes only the Verifier Seat and never repeats the Editor;
- preflight reserves exactly one optional Verifier recovery turn and its bounded token/time envelope;
- mocked integration coverage proves the initial path uses Editor plus Verifier while the recovery path uses exactly one Verifier call.

The stopped live room predates this checkpoint event and cannot be retroactively recovered. It remains in Meeting History for audit.

## Gate Result

**Fail the Artifact v2 user-outcome Gate; pass the failure-detection and recovery-design Gate.**

The benchmark provided real evidence that accepted Finding lineage reaches Editor selection and that rejected cross-review material stays excluded. It did not provide evidence for final Artifact quality, changed-material verification quality, reading effort, or Human Gate usefulness.

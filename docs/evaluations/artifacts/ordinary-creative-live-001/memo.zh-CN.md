# 建议

**推荐方向：都市异能/规则怪谈+系统流**，采用「完读率优先」的章节工程化设计，而非传统叙事结构。

核心理由：番茄平台以免费阅读+广告分成为主，完读率与追读率直接决定收益，题材选择只决定进入哪个流量池，留存设计才决定能否出池。都市异能/规则怪谈题材天然支持短周期爽点兑现，世界观构建成本低，且与TTS听书用户的「可听化」需求兼容。

**重要少数派意见**：有席位认为应根据作者个人优势（专业背景、写作风格、更新能力）因人而异推荐题材，而非一刀切。若作者有玄幻写作经验或特定行业背景，可考虑调整方向。

**需人工决策事项**：
1. 作者身份定位（新人/兼职/资深）——直接影响存稿量要求与止损策略
2. 日更能力上限（4000字/6000字/8000字）——决定节奏密度设计
3. 是否接受30章止损换书的风险管理策略

# 交付内容

## 一、定位与核心卖点

**题材定位**：都市异能·规则怪谈+系统流

**核心钩子**（一句话说清）：普通人在规则崩坏的都市中获得「规则解读系统」，能看穿一切怪谈规则的漏洞，以弱胜强、逆天改命。

**差异化设定**：
- 金手指不是直接变强，而是「看破规则」——主角通过系统提示发现怪谈规则的BUG，用智商+胆量碾压
- 都市背景降低世界观构建成本，读者代入感强
- 规则怪谈自带「即时死亡威胁+明确通关条件」，天然制造紧张感和爽点

## 二、主角与核心冲突

**主角设定**：
- 姓名：林默（易听辨、好记忆，适配TTS）
- 身份：刚毕业的普通大学生，父母失踪（伏笔），独自租住老旧小区
- 性格：表面普通，内核冷静、心狠、敢赌命
- 金手指：规则解读系统——能将怪谈规则以文字形式显示，并标注「可利用漏洞」

**核心冲突主线**：
- 表层冲突：在规则怪谈不断侵蚀的都市中活下去、变强
- 中层冲突：发现父母失踪与某神秘组织有关，追查真相
- 深层冲突：规则怪谈的源头是什么？系统的真正目的是什么？

## 三、长线主弧与分卷结构（5卷规划）

**第一卷·规则觉醒（1-50章，约25万字）**
- 主线：主角从普通人成长为初级怪谈猎人
- 核心任务：活过前三个怪谈事件，获得系统认可，进入官方「异常管理局」视野
- 爽点密度：每章1小爽（识破规则/反杀），每5章1大爽（通关怪谈/获得奖励/打脸看不起他的人）

**第二卷·势力初成（51-120章，约35万字）**
- 主线：加入异常管理局，组建小队，挑战B级怪谈
- 核心任务：收服2-3个各有特色的队友，建立个人势力
- 格局跃迁：从「个人求生」升级为「小队作战」

**第三卷·暗流涌动（121-200章，约40万字）**
- 主线：发现父母失踪与「深渊教团」有关，与官方产生路线分歧
- 核心任务：挑战A级怪谈，与深渊教团正面交锋
- 格局跃迁：从「执行者」升级为「有话语权的实力派」

**第四卷·真相浮现（201-300章，约50万字）**
- 主线：揭开系统来源与怪谈起源的部分真相
- 核心任务：救出父母（或发现已死）、清剿深渊教团核心
- 格局跃迁：从「地区势力」升级为「全国知名」

**第五卷·终局之战（301-400章，约50万字）**
- 主线：面对怪谈源头，决定人类命运
- 核心任务：与系统背后的存在对话，做出最终选择
- 格局跃迁：从「人类强者」升级为「规则制定者」

## 四、前10章逐章纲要（开篇生死线）

**第1章·规则降临（2000-2200字）**
- 前500字：林默下班回家，电梯里出现诡异提示「不要与第七个人对视」——世界规则崩坏的信号
- 本章爽点：系统激活，林默在最后一秒发现规则漏洞（第七个人是镜中倒影），反杀成功
- 章末钩子：系统提示「恭喜通过新手试炼，正式怪谈将于24小时后降临」——下一步动作已启动
- 信息增量：金手指亮相、主角性格展示（冷静、敢赌）

**第2章·租客失踪（2000-2200字）**
- 开篇：林默调查系统，发现楼里有租客神秘失踪
- 本章爽点：利用系统扫描发现502室是怪谈核心区，成功避开触发条件
- 章末钩子：502室门缝下伸出一只手，抓住了林默的脚踝
- 信息增量：建立「怪谈有明确规则，可被破解」的核心设定

**第3章·规则博弈（2000-2200字）**
- 开篇：502室怪谈正式触发，规则显示「在房间内每说一句话，就会失去一样东西」
- 本章爽点：林默发现漏洞——「写字不算说话」，用纸笔与怪谈周旋
- 章末钩子：发现房间内还有一个被困的女孩，她只剩最后一次说话机会
- 信息增量：引入第一个重要配角（苏晴），展示主角「救人」的底线

**第4章·以命换命（2000-2200字）**
- 开篇：林默必须选择——用自己的「东西」换女孩出去的机会
- 本章爽点：林默发现规则漏洞——「失去的东西可以是负面的」，故意说话失去「恐惧」
- 章末钩子：通关奖励是一张「怪谈碎片」，系统提示可用于强化
- 信息增量：建立成长体系（碎片收集→能力强化）

**第5章·第一个跟班（2000-2200字）**
- 开篇：苏晴（医学生）要求跟着林默，称自己也觉醒了能力——治愈系
- 本章爽点：林默测试苏晴能力，发现是真的，队伍+1
- 章末钩子：异常管理局的人找上门，给出两个选择：加入或被监控
- 信息增量：引入官方势力，展示更大的世界观

**第6章·官方接触（2000-2200字）**
- 开篇：异常管理局调查员态度傲慢，看不起林默这种「野路子」
- 本章爽点：林默当场用系统发现调查员身上有怪谈寄生，救了他一命，打脸成功
- 章末钩子：调查员改变态度，透露城市里将有大规模怪谈爆发
- 信息增量：建立「主角能力独特，官方也需要」的地位

**第7章·商场惊变（2000-2200字）**
- 开篇：林默在商场遭遇C级怪谈「永不停止的电梯」
- 本章爽点：第一次面对更高难度怪谈，靠规则理解在电梯里存活
- 章末钩子：发现电梯里还有其他困住的人，包括一个异常管理局的精英
- 信息增量：展示怪谈的等级体系

**第8章·电梯法则（2000-2200字）**
- 开篇：被困者包括管理局精英王铮，他态度恶劣，质疑林默能力
- 本章爽点：林默用系统发现通关关键，但王铮拒绝配合，差点全灭
- 章末钩子：林默强行执行计划，成功率只有30%
- 信息增量：塑造主角「敢赌命」的性格

**第9章·以弱胜强（2000-2200字）**
- 开篇：林默的计划执行中，王铮从阻碍变成助力
- 本章爽点：成功通关C级怪谈，所有人对林默刮目相看；王铮从傲慢变为服气
- 章末钩子：通关奖励揭示林默父母失踪的线索——他们可能还活着
- 信息增量：父母线伏笔激活，长线悬念建立

**第10章·新的起点（2000-2200字）**
- 开篇：林默正式收到异常管理局邀请，以「顾问」身份加入
- 本章爽点：确立地位——不是打工仔，而是有话语权的特殊存在
- 章末钩子：第一个正式任务：调查连环失踪案，目标地点——林默父母失踪的那条街
- 信息增量：第一卷核心任务正式启动

## 六、TTS可听化设计要点

- 短句为主，单句不超过30字
- 对话驱动情节，减少大段心理描写
- 人名易辨：林默、苏晴、王铮——避免谐音和生僻字
- 禁止倒叙和意识流，严格线性叙事
- 每章开头用一句话回顾上章关键事件

## 七、数据止损机制

| 阶段 | 检查点 | 止损线 | 行动 |
|------|--------|--------|------|
| 上线前 | 存稿量 | 至少30章完稿 | 未达标不上线 |
| 上线7天 | 追读率 | 低于同赛道均值50% | 重写前3章 |
| 上线30章 | 追读率 | 低于同赛道均值30% | 换书止损 |
| 上线50章 | 广告收益 | 日均低于XX元（自设） | 评估是否续写 |

**注**：具体追读率基准需通过分析同赛道头部作品前10章数据逆向推断。

## 八、风险与常见陷阱

**高风险项**：
1. 开局吃亏段写太长——首章前500字必须完成规则崩坏+系统亮相
2. 双线并进——前30章只走主线，副线30章后再接入
3. 世界观铺垫过多——规则只在需要时展示，禁止开篇设定倾泻

**常见陷阱**：
1. 「我的设定很新颖」心态——番茄读者对创新容忍度有限
2. 付费思维写章末——番茄是完读率导向，章末要「推进」不要「截断」
3. 日更断裂——建议存稿30章后再上线，保持稳定更新

# 共识

1. **平台机制共识**：番茄以免费+广告分成为主，完读率和阅读时长是决定收益的核心指标，故事结构应服务于「防划走」而非传统叙事美学。（claim-1, claim-7, 已获临时支持）

2. **听书适配共识**：番茄存在相当比例的TTS听书用户，文本需「可听化」，这会反向约束叙事结构与题材选择。（claim-8, 已获临时支持）

3. **方法论共识**：在缺乏平台公开数据的情况下，逆向分析同赛道头部作品的前10章结构是推断标准的务实替代方案。（claim-10）

4. **章末设计共识**：免费模式下，章末钩子应设计为「动作已启动」的推进式悬念，而非「信息被截断」的付费式吊胃口。（claim-11）

# 未解决分歧

1. **题材推荐是否应因人而异**：一方认为应根据作者个人优势定制推荐；另一方认为对新人而言，低构建成本的都市类题材是普遍最优解。此分歧需作者自评能力后人工决策。（dispute-1）

2. **套路与创新的平衡点**：「70%套路+30%微创新」的比例是否适用于所有情况存在争议；过度套路可能导致同质化，但过度创新可能导致读者流失。（dispute-2）

3. **30章止损线的具体阈值**：各方同意需要止损机制，但对「追读率达标线」的具体数值无法给出可验证的标准。需作者自设或参考同赛道数据。（dispute-4）

4. **前期是否可以双线并进**：技术席位提议的「门派恩怨+黑白两道」双线被批评为新人高风险结构，建议前30章只保留单线。（dispute-5）

# 未核实假设

1. 番茄TTS听书用户占比「相当」——无公开数据支撑，但多席位认同其存在并影响写作策略（中等置信度）

2. 番茄分发算法中题材标签与追读率的相对权重——无公开数据，各方基于行业经验推断（中等置信度）

3. 「日更4000字是基本门槛」——为行业惯例判断，非平台硬性要求（中等置信度）

4. 都市类题材对新人的世界观构建成本确实低于玄幻——基于合理推断，未有对照实证（中等置信度）

# 权衡

| 选项 | 优势 | 劣势 |
|------|------|------|
| 都市异能/规则怪谈 | 构建成本低、爽点周期短、可听化友好 | 赛道渐热，需靠执行力突围 |
| 传统玄幻升级 | 读者基数大、模式成熟 | 世界观负担重、同质化严重 |
| 赘婿/神医回归 | 爽点直接、入门易 | 套路疲劳明显、难出新意 |
| 全职投入长篇 | 更新稳定、沉浸深 | 沉没成本高、止损困难 |
| 兼职+存稿+止损 | 风险可控、试错空间大 | 更新节奏可能受影响 |

# 下一步

1. **作者自评**：确定自身能力档位（新人/兼职/资深）、日更上限、是否接受止损策略

2. **竞品分析**：找3-5本番茄同赛道头部作品，拆解其前10章结构，提取爽点密度和章末钩子模式

3. **存稿准备**：按上述大纲完成前30章存稿，每章控制在2000-2200字

4. **试水上线**：存稿完成后上线，7天检查追读率，30章决定是否止损或调整

5. **数据复盘**：建立个人数据记录表，追踪每章完读率与追读率变化，持续优化

# M2.11 校正简报：Verifier v2 Stage Replay

日期：2026-08-27
状态：已完成

## 已观察失败

本地 schema 与语义测试已经覆盖 Review Verifier v2 契约，但当前供应商与所选模型还没有在一次隔离调用中证明自己能返回准确、受限的 v2 Artifact。

## 用户 Artifact

一份供应商实测记录，用来证明或否定所选模型能否生成结构有效、语义独立的 Review verification Artifact，同时不运行或修改任何 Meeting。

## Baseline

更早的 Stage Replay 003 通过的是 v1 契约。v2 新增双重 lineage 与语义独立性检查，所以旧结果不能关闭当前供应商 Gate。

## 最小假设

当前已连接并选中的模型可以在一次供应商调用和 600 输出 token 上限内满足固定的 Review Verifier fixture v2。

## 预期信息增量

本次结果会区分供应商/模型兼容性问题与本地编排缺陷，并在无需支付完整会议成本的前提下暴露准确的 schema 或语义偏差。

## 验收检查

- 只进行一次供应商调用，不自动重试。
- 响应明确标识 fixture version 2。
- v2 schema 与语义检查通过；若失败，则将第一条诊断原样记录为证据。
- 记录输入 token、输出 token、估算费用和延迟。
- 不创建或修改 Meeting 记录。

## 成本边界

用户授权的供应商估算费用上限为 0.01 美元。Replay 的输出上限为 600 token，首次得到结果后必须停止。

## 停止条件

一次成功或一次失败后立即停止。本 Gate 不得原样重试、切换模型，也不得运行完整 Review/Plan 流程。

## 结果

假设通过。Anthropic `claude-haiku-4-5-20251001` 在一次调用中返回有效 fixture-v2 Artifact：597 input tokens、224 output tokens、3.1 秒和 `$0.0034` 应用估算。`lineage` 与 `semantics` 分别独立支持 `change-replay-1`，没有 unresolved 项。Meeting History 保持 10 条。没有重试或新增供应商调用。见 [Stage Replay 008](../evaluations/2026-08-27-v0.11-verifier-v2-stage-replay-008.md)。

# M2.12 校正简报：固定 S1 入口

日期：2026-08-27
状态：本地完成；真实 S1 未运行

## 已观察失败与基线

离线对照包能导出正确 S1 提示，但应用唯一的单调用入口运行的是 Verifier fixture，普通 Review 则需多次调用。两者都不能在不改变实验、也不提取 key 的前提下，使用会话 BYOK 保存纯文本单模型基线。

## 用户产物与最小假设

只在现有开发 Replay 选择器里增加 `resume-truth-v1` S1。一次明确动作复用正常供应商适配器，保存纯文本及不含凭证的证据回执，不写 Meeting。复用准确离线提示构造器，oracle 不进入服务端路径。这是固定评测入口，不是通用提示游乐场。

## 验收与信息增量

- 既有 Verifier 行为不变。
- S1 仅用服务端固定公开案例，一次调用、2,400 输出 token 上限、无重试。
- 返回准确 system/user 提示、输入/提示哈希、模型/配置、原始输出及已知用量；拿到回复只代表未评分候选，不代表语义通过。
- 保存部分失败输出并标记用量未知；只下载不含凭证的回执，不包含 key 或 Meeting 状态。
- 注入 prompt/case/output-limit 字段在供应商调用前拒绝。
- 模拟测试证明边界，本地 UI 检查不发调用。

## 成本与停止

实现期间零真实供应商调用。当前浏览器没有 Connection。真实 S1 运行需要重新连接、明确模型和新的预算批准。完成该窄入口及测试即停止；不建设模型市场、批处理器、新基线协议，不部署、不扩建其他 UI。

## 结果

固定入口、共用提示、可下载回执和部分失败路径通过本地验证。Build、全部 38 项测试和 ESLint 通过；浏览器确认无 Connection 时 S1 动作禁用。未调用供应商。真实 S1 质量和对照结果仍未运行，等待连接/模型/预算批准。

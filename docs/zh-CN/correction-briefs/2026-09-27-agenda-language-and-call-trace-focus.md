# DP-0.3 — Agenda 语言与会议 trace 焦点纠错

- **已观察失败：** 普通会议的提案、交叉审阅、定向回复和总结 prompt 都以英文撰写，只有可选的 unlimited 深度总结明确要求跟随目标语言。用户看到发言／输出偏离 Agenda 语言。P2 的 `SourceAttemptView` 是 `.meeting-workspace` 的第四个直接子节点，但网格只声明三行；trace 占用了发言／转录区域的空间，把会议内容挤走。
- **用户产物：** 参与者发言和决策正文跟随输入 Agenda 的主要自然语言；call 证据仍可按需查看，但默认视觉主体是发言、会议记录和控制。
- **基线：** 当前普通回合 system 指令没有 Agenda 语言规则；总结格式需要固定英文机器章节标签。有回执时 trace 始终夹在工具栏和会议内容之间，即使 `<details>` 关闭也在布局流内。
- **最小假设：** 给普通 Turn Envelope 调用加一条共用语言规则，明确保留 JSON 键和结构性章节标签；明确中文目标使用中文章节标签，同时仍接纳旧英文格式。将 trace 入口放入 Meeting 工具栏，内容作为按需覆盖层显示，不参加主网格排版。
- **预期信息增益：** 模拟调用可证明所有普通阶段收到语言指令，零付费调用。组件渲染和窄视口检查可证明关闭的 trace 不占发言网格行，展开后仍显示原有安全回执。
- **验收：** 中英文 Agenda fixture 在提案、审阅、定向辩论和总结阶段保留可见语言方向；中文 memo 正文与本地化标题通过既有有界结构检查，旧英文标题继续有效。不退化校验、预算、重试或回执持久化。关闭 trace 时会议内容保有完整网格行；展开入口可由键盘操作且内容可读。`pnpm.cmd check` 通过。
- **成本边界：** 不调用供应商、不加依赖、不迁移记录、不改导出、不部署。P2 证据含义与隐私边界不变。
- **停止条件：** 若模拟输出仍偏离，不新增修复调用或按付费回答推断语言；记录 prompt-only 限制。若测试宽度下覆盖层遮挡操作，调整覆盖层边界，不改变会议主网格。

## 本地结果

- 普通回合共用指令现要求每个 Seat 跟随 Agenda 的主要语言和文字，包括定向辩论。明确中文目标的 Decide/Review 总结使用中文章节标题；格式检查仍接纳旧英文标题。其他语言的正文按 Agenda 指令生成，结构性标题暂沿用原格式。
- Call trace 默认收起，入口位于 Meeting 工具栏，展开后在有滚动边界的覆盖层中查看。回执内容、语义、持久化和导出不变；trace 不再占会议网格的一行。
- `pnpm.cmd check` 通过：构建、77/77 离线测试、lint 与生成类型检查。模拟中文 Decide/Review 流验证语言指令和中文最终标题；定向辩论 fixture 验证共用指令；组件渲染与源码检查验证默认收起及工具栏位置。零付费调用。
- **仍未验证：** 真实模型是否严格遵从语言指令、浏览器中的实时／恢复会议视口、以及窄屏下带真实回执的覆盖层。Prompt 指引不是语言保证；此处停止，不增加付费重试或扩大范围。

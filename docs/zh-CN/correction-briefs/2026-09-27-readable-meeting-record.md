# 修正简报：可读会议与完整记录导出

- 已观察问题：用户的中文创作会议在 Focus/Overview 中露出 Markdown 标记；现有脱敏诊断 JSON 按设计不包含会议内容。人工 Chair 指令也不在发言数组中。
- 用户交付物：可读的会议页面，以及进行中或结束后可主动下载的一间已保存房间 Markdown 记录，包含议程、席位供应商/模型/角色、按顺序的发言、已保存人工指令、用量和最终产物/状态。
- 基线：纯文本显示；只有脱敏诊断导出；重建会议需人工截图与复制。
- 最小假设：安全渲染 GFM，并将现有房间和 Chair 事件投影为独立 Markdown 文件。不改模型提示、协议、存储模式或诊断导出。
- 信息增益：仅做确定性的界面和导出验证；零模型调用。
- 验收：标题/列表/表格正常呈现，原始 HTML 不执行；单房间 UTF-8 文件保留发言顺序，并将人工指令锚定在记录中的前一条发言之后；不编造密钥、缺失时间或未保存内容；进行中与归档入口可用；离线测试、构建、检查通过。
- 成本边界：无付费调用或自动重试；仅增加安全 GFM 渲染依赖；不增加持久化 store。
- 停止条件：止于现有记录的准确投影。旧房间缺人工事件或单次发言时间时明确标注，不从模型文字猜测，不扩展成通用 SDK/导入导出平台。

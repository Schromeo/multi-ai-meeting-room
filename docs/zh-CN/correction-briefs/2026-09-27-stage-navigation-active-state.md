# 修正简报：步骤导航选中态

- 已观察问题：用户选到其他页面后，顶部／底部编号栏中的 Setup 仍高亮。源码把 Setup 的 `active` 绑在就绪席位少于两个，与 `stage` 无关。
- 用户交付物：共用的桌面／移动导航同一时刻只高亮当前一步；连接设置弹窗打开时高亮 Setup，否则由可见的 Agenda／Meeting／Decision 页面决定。席位就绪仍单独显示完成态。
- 基线：不足两个就绪席位时，Setup 与所选页面可能同时带 `active`。
- 最小假设：四步高亮统一从当前 UI 位置（`connectionOpen` 或 `stage`）计算，而非从席位就绪推断。
- 预期信息增益：仅本地 UI 状态与源码检查；不调用供应商。
- 验收：0–2 个就绪席位时，Agenda／Meeting／Decision 不双高亮；打开／关闭 Setup 只切换当前高亮；既有完成态与禁用行为不变；项目检查通过。
- 成本边界：仅页面表达式和定向测试；无模型调用、持久化变化或新依赖。
- 停止条件：选中态正确即停止，不重做导航或阶段路由。

# v0.11 Artifact v2 Benchmark 002

**日期：** 2026-08-26

**状态：** 在 Verifier 边界停止。真实房间没有生成可批准的 Artifact v2，也没有重新创建房间。

**批准上限：** 单个有限房间 `$0.10`。供应商账单仍是权威依据。

## 目标与配置

- 沿用 Benchmark 001 的同一份简历与归档 Google JD 案例，并在发送前删除个人标识。
- OpenAI `gpt-4.1-mini` 担任 Strategist 和确定性 Editor。
- Anthropic `claude-haiku-4-5-20251001` 担任 Critical Reviewer 和改动部分 Verifier。
- Checkpoints 模式、一轮、Observer 关闭。
- 两次独立 Finding、两次 cross-review、一次 Editor 和一次 Verifier 调用。
- 可信当前日期为 `2026-08-26`；不得虚构指标、日期、ownership、资格、引用、无障碍经历或 AI 工具影响。

## Chair 决定

系统发布六个独立 Finding，Chair 接受两项具体修改：

1. 删除未完成的 AI-tool 占位符，不虚构用法或影响。
2. 弱化 Nature Conservancy 的 `~50%` 提升，因为用户材料没有给出 baseline 或测量方法。

Chair 拒绝了无需修改的正面教育观察、重复占位符 Finding、过度宽泛的 metrics 批评，以及会削弱简历中已有来源描述的 VecDB benchmark 的建议。

Cross-review 保留了全部 Human Choice。它新增了 ownership scope 风险，但该项没有被 Chair 接受，因此不能进入 Editor 契约。

## 失败一：Verifier 契约

Editor 已完成，并通过严格 Change Set parser。Anthropic Verifier 随后返回了未通过顶层 changed-material 契约的结构化输出。原 parser 只返回笼统 mismatch，无法观察具体错误字段。

在不增加供应商调用的情况下完成以下修正：

- prompt 现在会根据每个真实 Change ID 生成具体响应骨架；
- 顶层只允许 `summary`、`checks` 和 `unresolved`；
- 明确禁止模型自行增加 `verdict`、`confidence` 和 `evidence` 字段；
- 每个 status 必须选择一个字面值，不能原样输出管道分隔的选项列表；
- parser 现在分别报告无效 JSON、缺少或多余 key、数组错误、未知 Change ID、无效 status 和 note 长度错误。

## 失败二：虚假的恢复边界

旧 v0.11c 把 Editor 与 Verifier 组合在一个 synthesis transition。虽然 UI 提供显式 Resume，但失败 transition 已消耗两个预留 agent turn，Resume 因此在供应商调用前直接以 `Budget exhausted` 停止。

这与产品的恢复承诺冲突；即使增加预算，旧路径也会重复已经成功的 Editor 调用。

在不增加供应商调用的情况下完成以下修正：

- 经过验证的 Editor 结果现在会发出并持久化 `ReviewEditCheckpoint`，其中包含 Change Set、确定性 Artifact v2、Editor 快照、来源 State 版本和创建时间；
- 恢复请求必须匹配同一 State 版本、已接受 Finding、Artifact v1 和确定性 Editor；
- Resume 只路由 Verifier Seat，不再重复 Editor；
- 预检恰好预留一次可选 Verifier 恢复 turn 及其有限 token/time envelope；
- 模拟集成测试证明初始路径调用 Editor+Verifier，而恢复路径只调用一次 Verifier。

这个已停止真实房间早于 checkpoint 事件，无法retroactively恢复；它继续留在 Meeting History 供审计。

## Gate 结果

**Artifact v2 用户成果 Gate 失败；失败检测与恢复设计 Gate 通过。**

本次 benchmark 提供了真实证据：已接受 Finding 来源链能到达 Editor 选择，被拒绝的 cross-review 内容仍被排除。但它没有证明最终 Artifact 质量、改动核验质量、阅读负担或 Human Gate 价值。

## 下一动作

不增加更多 Review 功能。获得新一轮明确预算并重新挂载 session connection 后，在同一案例上运行一次替代 Artifact v2 benchmark。合法运行必须直接完成，或在 Verifier 一次格式失败后恢复已保存 Editor checkpoint，并且只调用 Verifier。判断 Artifact 质量前先记录汇总用量。

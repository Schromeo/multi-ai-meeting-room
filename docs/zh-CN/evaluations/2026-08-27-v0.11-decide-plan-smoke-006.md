# Decide / Plan Smoke 006

日期：2026-08-27
状态：协议通过；产物质量失败

## 目标

为能够完成 Easy 和部分 Medium 的求职者生成完整 12 天 LeetCode 计划。请求的产物必须包含每日主题、模式、建议题目与数量、时间分配、复盘方法、阶段检查、调整规则、休息，以及对缺少个性化信息的明确假设。

## 配置

- Task Pack：Decide / Plan
- OpenAI `gpt-4.1-mini`：Strategist 与 Synthesizer
- Anthropic `claude-haiku-4-5-20251001`：Technical Lead
- 一轮、Checkpoints、Observer 关闭
- 用户上限：`$0.10`

## 证据

- Proposal 与 cross-review 完成。工作发言较短符合预期，因为它们的 transport 契约仍分别限制为 140 和 120 words。
- 第一次 synthesis 输出 702 tokens 后 Turn Envelope 校验失败，原因是 synthesis 不使用的 card delta 超出管理契约。
- 后续 synthesis 在旧的 1,200-token 边界结束为无效 JSON；没有原样重复调用。
- 显式恢复最初在到达供应商前以 `The bounded phase context is invalid.` 本地失败。保存的 transcript 含有不属于当前 Canonical State 的废弃 turn。
- 改为只使用 canonical context 后，一次 OpenAI synthesis 完成：1,585 output tokens、22 秒，应用估算 `$0.013`。
- 房间总计显示 11K input tokens、3,974 output tokens、71 秒和 `$0.044` 应用估算；供应商账单仍是权威依据。

## Gate 结果

可恢复协议、混合供应商路径、有限预算与较长 synthesis transport 通过。用户产物 Gate 失败：memo 覆盖了 12 天、时间、checkpoint、调整、休息和假设，却用“数组”“链表”等类别标签替代了用户明确要求的具体 LeetCode 题目。

实现现在以 Canonical State 作为恢复 phase context 的权威来源，忽略废弃 transcript turn；本地且未到达 provider 的拒绝不会吞掉 provider 调用额度；synthesis 输出上限为 2,400；Decide memo 标题由代码校验。日程型 Plan 必须覆盖每个请求日期；明确要求题目的 LeetCode 计划必须给出具体题号，不能只给类别。
